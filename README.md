# xingmf-site

这是一个静态的中文信息检索工作台，聚合了：

- 生活有据：政府公开信息检索
- 信息素养框架：高等教育信息素养知识图谱
- 参考文献学习：引用与文献规范学习
- GB/T 7714：文献类型与代码全景图
- 高校培训图谱：信息素养培训课程结构

## 访问方式

直接打开以下任一文件即可：

- `all-in-one.html`：统一工作台入口
- `index.html`：生活有据单页入口

## 本地预览

可直接使用浏览器打开 `all-in-one.html`，也可以在任意静态文件服务器中托管本目录。

例如：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/all-in-one.html
```

## 说明

本项目主要使用原生 HTML/CSS/JavaScript，没有额外构建依赖，适合直接部署到 GitHub Pages、静态托管平台或本地文件环境中。
